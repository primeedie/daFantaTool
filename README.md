# daFantaTool by primeedie

[Open the dashboard](https://primeedie.github.io/daFantaTool/)

Fantasy hoops for our Yahoo league. Pick Trading Tool or Other Thing on the home page.

ESPN stats refresh hourly, with an extra update at 3 PM Manila. Yahoo rosters are updated from screenshots. Other Thing uses a browser password prompt. The Pages snapshot is public.

Local: `npm start`. Checks: `npm test`.
