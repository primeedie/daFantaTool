About the project

Built for the
love of the game.

An independent, non-commercial personal software project. The initial version is intended for one account owner managing one team in a private Yahoo Fantasy basketball league.

The planned integration requests read-only league settings, standings, rosters, matchups, player statistics, available players, waiver information, and transactions. Daily refreshes are planned after API approval and setup.
